# Задача 6

## Написать программу для проверки наличия комментария в первой строке файлов с расширением c, js и py.

### Код программы
```
nano comments

#!/bin/bash

find . -type f \( -name "*.c" -o -name "*.js" -o -name "*.py" \) | while read file
do
    first=$(head -n 1 "$file")

    if [[ "$file" == *.py ]]; then
        [[ "$first" == \#* ]] && echo "$file: есть комментарий" || echo "$file: нет комментария"
    else
        [[ "$first" == //* || "$first" == /* ]] && echo "$file: есть комментарий" || echo "$file: нет комментария"
    fi
done
```

### Пояснение
```
nano comments - Создаём программу

#!/bin/bash - программа должна выполняться через Bash

find . -type f \( -name "*.c" -o -name "*.js" -o -name "*.py" \) - Таким образом, команда находит файлы .c, .js и .py
  - find — ищет файлы.
  - . — искать в текущем каталоге и его подкаталогах.
  - -type f — искать только файлы.
  - -name "*.c" — файлы с расширением .c.
  - -o — означает «или».
  - \( и \) — объединяют условия поиска.

| while read file - Передаёт найденные пути в цикл. Переменная file получает имя очередного файла

do и done - Обозначают начало и конец цикла.

first=$(head -n 1 "$file") - Считывает первую строку файла и сохраняет её в переменную first.
  head — показывает начало файла.
  -n 1 — только первую строку.
  $(...) — выполняет команду и сохраняет её результат.

if [[ "$file" == *.py ]]; then - Проверяет, заканчивается ли имя файла на .py
[[ "$first" == \#* ]] - Проверяет, начинается ли первая строка Python-файла с символа #, которым обозначают комментарии.

[[ "$first" == //* || "$first" == /* ]] - Для файлов C и JavaScript проверяет, начинается ли строка с // или /* — распространённых обозначений комментариев.

&& echo ... || echo ... - Если условие выполнено, выводится «есть комментарий», иначе — «нет комментария».

Запускаем программу:
chmod +x comments - 
./comments
```
