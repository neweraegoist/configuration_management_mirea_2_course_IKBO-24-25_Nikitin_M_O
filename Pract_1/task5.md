# Задача 5 

## Написать программу для регистрации пользовательской команды (правильные права доступа и копирование в /usr/local/bin). Например, пусть программа называется reg:
```
./reg banner
```
В результате для banner задаются правильные права доступа и сам banner копируется в /usr/local/bin.

### Код программы
```
nano banner

#!/bin/bash

text="$1"
length=${#text}

echo "+-$(printf '%*s' "$length" '' | tr ' ' '-')-+"
echo "| $text |"
echo "+-$(printf '%*s' "$length" '' | tr ' ' '-')-+"
```

```
nano reg

#!/bin/bash
chmod 755 "$1"
sudo cp "$1" /usr/local/bin/

chmod +x banner
chmod +x reg

./reg banner

banner Hello
```

### Результат вывода
```
+-------+
| Hello |
+-------+
```

### Пояснение
```
nano banner - Создание программы banner

#!/bin/bash - Программа выполняется с помощью интерпретатора Bash

text="$1" - Создаёт переменную text и записывает в неё первый аргумент
length=${#text} - Вычисляет количество символов в переменной text и записывает результат в переменную length.

echo "+-$(printf '%*s' "$length" '' | tr ' ' '-')-+" - Эта строка выводит верхнюю границу рамки.
  echo — выводит текст на экран.
  +- и -+ — символы, которые образуют края рамки.
  $(...) — выполняет команду внутри скобок и подставляет её результат.
  printf '%*s' "$length" '' — создаёт строку из пробелов нужной длины.
  | — передаёт результат первой команды следующей.
  tr ' ' '-' — заменяет все пробелы на дефисы -.

echo "| $text |" - Выводит текст внутри рамки.
  | — вертикальные границы.
  $text — текст, который передали программе.

echo "+-$(printf '%*s' "$length" '' | tr ' ' '-')-+" - Эта строка выводит нижнюю границу рамки.
  +- и -+ — символы, которые образуют края рамки.
  $(...) — выполняет команду внутри скобок и подставляет её результат.
  printf '%*s' "$length" '' — создаёт строку из пробелов нужной длины.
  | — передаёт результат первой команды следующей.
  tr ' ' '-' — заменяет все пробелы на дефисы -.
```

```
nano reg - Создание программы reg

#!/bin/bash - Программа выполняется с помощью интерпретатора Bash
chmod 755 "$1" - Изменяет права доступа к файлу, имя которого передано первым аргументом.
  Число 755 означает:
    - 7 — владелец может читать, изменять и запускать файл.
    - 5 — группа может читать и запускать файл.
    - 5 — остальные пользователи тоже могут читать и запускать файл.
sudo cp "$1" /usr/local/bin/ - Копирует программу в системный каталог.
  sudo — выполняет команду с правами администратора, если это разрешено системой.
  cp — команда копирования файлов.
  "$1" — имя исходного файла, в нашем случае banner.
  /usr/local/bin/ — каталог для пользовательских исполняемых программ, которые можно запускать как обычные команды.


chmod +x reg - Добавляет файлу reg право на выполнение
chmod +x banner - Добавляет файлу banner право на выполнение

./reg banner - Запускает программу reg и передаёт ей аргумент banner

banner Hello - Запускает зарегистрированную программу уже по имени
```
