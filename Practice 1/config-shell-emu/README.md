## О чём эта программа

Это небольшая программа, которая работает как простая командная строка. Пользователь вводит команду, программа разбирает её и выполняет.

Вместо настоящих файлов компьютера используется виртуальная файловая система (VFS). Она хранится в памяти программы и загружается из XML-файла.

В работе сделаны только первые три этапа задания:
- этап 1 — ввод и выполнение команд;
- этап 2 — запуск с параметрами и выполнение команд из файла;
- этап 3 — загрузка и использование виртуальной файловой системы.

```text
config-shell-emu/

├── run_tests.sh
├── README.md
```

В папке `src` находятся два основных файла:

- `emulator.py` — принимает команды, разбирает их и запускает.
- `vfs.py` — загружает XML и создаёт виртуальные папки и файлы.

## Что умеет программа

### Команды

| Команда | Что делает | Пример |
|---|---|---|
| `ls` | Показывает файлы и папки в текущем каталоге. | `ls` |
| `ls путь` | Показывает содержимое указанного каталога или имя файла. | `ls home` |
| `cd путь` | Переходит в другой каталог. | `cd home` |
| `cd ..` | Переходит на уровень выше. | `cd ..` |
| `cd /` | Переходит в корневой каталог. | `cd /` |
| `exit` | Завершает работу программы. | `exit` |
| `exit 1` | Завершает работу с кодом выхода 1. | `exit 1` |

Если написать неизвестную команду или передать неправильные аргументы, программа покажет ошибку.

Аргументы с пробелами можно писать в кавычках:

```text
ls "my folder"
ls 'my folder'
```

### Параметры запуска

У программы есть два параметра:

- `--vfs` — путь к XML-файлу с виртуальной файловой системой.
- `--script` — путь к текстовому файлу со списком команд.

Например:

```bash
./run.sh --vfs demo/vfs.xml
```

Запуск команд из файла:

```bash
./run.sh --vfs demo/vfs.xml --script demo/stage2_script.txt
```

При запуске программа показывает переданные параметры. Команды из стартового файла выполняются по порядку. Если одна из команд завершилась ошибкой, скрипт останавливается. Команда `exit` также завершает выполнение скрипта.

Если параметр `--vfs` не указан, программа запускается с пустой виртуальной файловой системой.

## Как устроена VFS

Виртуальная файловая система загружается из XML-файла. В нём используются два основных элемента:

- `dir` — папка;
- `file` — файл.

Пример:

```xml
<vfs>
    <dir name="home">
        <file name="hello.txt">Привет!</file>
    </dir>
    <file name="info.txt">Файл в корне</file>
</vfs>
```

После загрузки программа создаёт объекты папок и файлов в памяти. У папки могут быть вложенные папки и файлы. У каждого объекта есть имя и ссылка на родительскую папку.

В проекте есть два примера:
- `vfs_min.xml` — простая файловая система с одним файлом;
- `vfs.xml` — файловая система с несколькими папками и вложенными каталогами.

Команды `ls` и `cd` работают с этой виртуальной структурой. Реальные файлы на компьютере они не меняют.

## Как запустить

Для работы нужен Python 3.9 или новее. Дополнительные библиотеки устанавливать не нужно.

Откройте терминал в папке `config-shell-emu`.

Сначала можно выдать скриптам право на запуск:

```bash
chmod +x run.sh run_tests.sh scripts/*.sh
```

Запуск программы с основной VFS:

```bash
./run.sh --vfs demo/vfs.xml
```

Запуск с минимальной VFS:

```bash
./run.sh --vfs demo/vfs_min.xml
```

Запуск без VFS:

```bash
./run.sh
```

## Как проверить работу

Автоматические тесты запускаются командой:

```bash
./run_tests.sh
```

Если скрипт не запускается напрямую, можно выполнить его через Bash:

```bash
bash run_tests.sh
```

Тесты проверяют:
- разбор команд и аргументов в кавычках;
- ошибки при неизвестной команде и незакрытых кавычках;
- остановку стартового скрипта при ошибке и после команды `exit`;
- загрузку XML и проверку его структуры;
- работу команд `ls` и `cd` с разными путями.

Для демонстрации также есть скрипты в папке `scripts`:

```bash
bash scripts/test.vfs.sh
bash scripts/test_all.sh
bash scripts/test_script.sh
```

Последний скрипт запускает пример без загрузки VFS. Поэтому команда перехода в каталог `home` выдаёт ошибку: в пустой файловой системе такого каталога нет. Это сделано для демонстрации обработки ошибок.
