# Конфигурационное управление — ПР №1

**Вариант №16:** Эмулятор для языка оболочки UNIX-подобной ОС.

## 1. Общее описание
Программа представляет собой консольный эмулятор командной строки, написанный на Python. Эмулятор имитирует работу терминала, поддерживает базовые команды и использует виртуальную файловую систему (VFS), которая загружается в оперативную память из XML-файла.

**Что было сделано по этапам:**
- **Этап 1 (REPL):** Создан цикл чтения команд, парсер (с поддержкой кавычек) и команды-заглушки `ls`, `cd`, `exit`. Обрабатываются ошибки ввода.
- **Этап 2 (Конфигурация):** Добавлены параметры запуска (`--vfs`, `--script`). Эмулятор умеет читать стартовый скрипт, имитировать ввод и останавливаться при первой ошибке.
- **Этап 3 (VFS):** Написана виртуальная файловая система. Команды `ls` и `cd` теперь реально работают с виртуальными папками и файлами в памяти (без изменения реального диска).

## 2. Функции и настройки
**Параметры запуска:**
- `--vfs <путь>` — путь к XML-файлу с файловой системой.
- `--script <путь>` — путь к файлу, содержащему команды для автоматического выполнения.

**Доступные команды:**
- `ls [путь]` — вывести содержимое папки.
- `cd <путь>` — перейти в другую папку.
- `exit [код]` — выйти из эмулятора.

## 3. Сборка и запуск
Требуется Python 3.9+.

Сделать скрипты исполняемыми (один раз):
```bash
chmod +x run.sh run_tests.sh scripts/*.sh

Запуск эмулятора в интерактивном режиме:
./run.sh --vfs demo/vfs.xml

Запуск тестов для проверки работоспособности:
./run_tests.sh
