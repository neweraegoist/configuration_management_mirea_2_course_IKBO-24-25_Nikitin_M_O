# Практическая работа №2 — Вариант 16
## Построение графа зависимостей Maven

Практическая работа по дисциплине «Конфигурационное управление».

Программа написана на Python. Она получает зависимости Java-пакетов из Maven, строит граф зависимостей, находит циклы, определяет порядок загрузки и создаёт описание графа в формате PlantUML.

Для проверки программы без подключения к интернету предусмотрен тестовый режим.

## 1. Что умеет программа

Программа выполняет следующие действия:

- Читает настройки из XML-файла.
- Получает прямые зависимости Maven-пакета.
- Строит полный граф зависимостей.
- Находит циклические зависимости.
- Ограничивает глубину построения графа.
- Рассчитывает порядок загрузки пакетов.
- Сравнивает результаты с Apache Maven.
- Создаёт описание графа в PlantUML.
- Выводит граф в виде ASCII-дерева.

## 2. Что необходимо для запуска

- Python 3.9 или новее.
- pytest для запуска автоматических тестов.
- Apache Maven — только для сравнения результатов с Maven.

Основная программа использует стандартные библиотеки Python.

Установка зависимостей:

```bash
python3 -m pip install -r requirements.txt
```

## 3. Настройки программы

Все настройки хранятся в XML-файле.

Пример:

```xml
<config>
    <package_name>A</package_name>
    <repository>test_repo_simple.txt</repository>
    <test_mode>true</test_mode>
    <version>1.0</version>
    <ascii_tree>true</ascii_tree>
    <max_depth>10</max_depth>
</config>
```

Описание параметров:

| Параметр | Назначение |
|---|---|
| `package_name` | Название пакета или Maven-координаты |
| `repository` | Адрес Maven-репозитория или путь к тестовому файлу |
| `test_mode` | Включает или отключает тестовый режим |
| `version` | Версия пакета |
| `ascii_tree` | Включает вывод ASCII-дерева |
| `max_depth` | Максимальная глубина графа |

В тестовом режиме используются простые имена пакетов, например A, B и C.

В обычном режиме используются Maven-координаты вида `groupId:artifactId`.

## 4. Этапы практической работы

### Этап 1. Чтение конфигурации

Программа открывает XML-файл, считывает шесть параметров и проверяет их значения.

Если в настройках есть ошибка, программа выводит сообщение с указанием неправильного параметра.

Запуск:

```bash
./run.sh examples/config_test_simple.xml --stage 1
```

### Этап 2. Получение прямых зависимостей

Программа получает POM-файл выбранного Maven-пакета и определяет его прямые зависимости.

В тестовом режиме зависимости читаются из обычного текстового файла.

Запуск:

```bash
./run.sh examples/config_test_simple.xml --stage 2
```

Пример результата:

```text
Прямые зависимости A:
- B
- C
```

### Этап 3. Построение графа зависимостей

Программа проходит по зависимостям с помощью итеративного алгоритма DFS.

Она находит связанные пакеты, проверяет наличие циклов и учитывает максимальную глубину.

Запуск:

```bash
./run.sh examples/config_test_simple.xml --stage 3
```

Для проверки циклов:

```bash
./run.sh examples/config_test_cycle.xml --stage 3
```

Для проверки ограничения глубины:

```bash
./run.sh examples/config_test_depth.xml --stage 3
```

### Этап 4. Определение порядка загрузки

Программа рассчитывает порядок, в котором нужно загружать пакеты.

Сначала загружаются зависимости, затем пакеты, которые от них зависят.

Если в графе обнаружен цикл, программа сообщает, что правильный порядок загрузки определить нельзя.

Запуск:

```bash
./run.sh examples/config_test_simple.xml --stage 4
```

Для сравнения с Apache Maven:

```bash
./run.sh examples/config.xml --stage 4 --compare-maven
```

Для сравнения необходим установленный Apache Maven и доступ к репозиторию.

### Этап 5. Визуализация графа

Программа формирует описание графа в формате PlantUML.

Также можно включить вывод ASCII-дерева через параметр `ascii_tree`.

Запуск:

```bash
./run.sh examples/config_test_simple.xml --stage 5
```

Полученное описание PlantUML можно использовать для создания изображения графа с помощью PlantUML.

## 5. Демонстрационные графы

В папке `examples` находятся три дополнительных графа:

- `config_demo_alpha.xml`
- `config_demo_beta.xml`
- `config_demo_gamma.xml`

Они позволяют проверить программу на разных структурах зависимостей, включая общие узлы и циклические связи.

Запуск:

```bash
./run.sh examples/config_demo_alpha.xml --stage 5
./run.sh examples/config_demo_beta.xml --stage 5
./run.sh examples/config_demo_gamma.xml --stage 5
```

Готовые текстовые описания диаграмм находятся в папке `examples/results`.

Это демонстрационные тестовые графы, а не реальные Maven-пакеты.

## 6. Проверка с помощью Apache Maven

Для дополнительной проверки предусмотрено сравнение с командой:

```bash
mvn dependency:tree
```

Программа сравнивает найденные зависимости с результатом Maven и показывает, есть ли различия.

При проверке пакета `org.apache.commons:commons-text:1.11.0` состав зависимостей совпал.

Порядок вывода отличается, потому что Maven показывает дерево от основного пакета к зависимостям, а программа рассчитывает порядок загрузки — от зависимостей к основному пакету.

## 7. Автоматические тесты

Для проверки проекта используется pytest.

Запуск всех тестов:

```bash
python3 -m pytest tests -v
```

Или:

```bash
./run_tests.sh
```

В проекте предусмотрено 46 автоматических тестов.

Они проверяют:

- Чтение и проверку XML.
- Обработку неправильных настроек.
- Получение зависимостей Maven.
- Чтение тестовых графов.
- Поиск циклов.
- Ограничение глубины.
- Расчёт порядка загрузки.
- Создание PlantUML и ASCII-дерева.
- Работу основных этапов программы.

Последняя проверка: 46 тестов пройдены успешно.
